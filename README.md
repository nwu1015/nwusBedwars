# BedWars Plugin

Цей проєкт є базовою реалізацією плагіна **BedWars** для серверів **Minecraft Spigot (1.21+)**.  
Плагін має модульну структуру для зручного розширення (команди, слухачі, менеджери, конфігурації тощо).

---
## Основні модулі

| Модуль        | Призначення                                                       |
|---------------|-------------------------------------------------------------------|
| `nwusBedwars` | Точка входу в плагін, реєструє команди та слухачі.                |
| `commands`    | Реалізація команд `/bw create`, `/bw list`.                       |
| `game`        | Логіка гри: арени, спавнера.                                      |
| `listeners`   | Реакція на події гравців (вхід, вихід, знищення блоку).           |
| `utils`       | Допоміжні класи, наприклад, копіювання світу.                     |
| `configs`     | Робота з файлом `config.yml` і зчитування налаштувань.            |
| `events`      | Робота з подіями під час гри (знищення/розміщення блоків і т.д.). |
| `gui`         | Вікна меню (наприклад для вибору команди)                         |

---

## Встановлення та запуск

### Попередні вимоги
- Java **17** або новіше  
- Сервер **Spigot** версії **1.21+**  
- **Maven** (для компіляції)

---

У проєкті виконай: Maven -> Lifecycle -> install
Після збірки з’явиться файл: target/nwusbedwars-1.0-SNAPSHOT.jar
